# POS Web Application - Tech Hardware Store

## Store Theme
- **Niche:** Tech Hardware & Accessories
- **Description:** A point of sale web application designed for cashiers to build shopping carts, manage inventory, process customer sales, and review completed transaction history.

## How to Run the Application
1. Open `IT_ELECTIVE_2_MIDTERM_H1_H2_H3.sln` in Visual Studio 2022.
2. Ensure `.NET 8.0 SDK` is installed.
3. Press `Ctrl + F5` to run the project.
4. Access **Catalog**, **Shopping Cart**, **Checkout**, and **Transactions** from the top navigation bar.

## Features Implemented
- US-01: Product Browsing with stock badges & out-of-stock highlights.
- US-02: Shopping Cart using `AddToCartDTO`.
- US-03 & US-04: Quantity Management & Item Removal.
- US-05: Checkout using `CheckoutDTO` with automatic stock deduction.
- US-06: Transaction History & Order Details view.
